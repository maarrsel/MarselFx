## ✦ About the Project

Welcome to **Marsel FX**, an independent collection of creative video editing tools built with experimentation, AI-assisted development, and a passion for making editing more enjoyable.

The goal is simple:

**Powerful creative tools should be accessible to everyone.**

From cinematic lighting and analog textures to dynamic motion and expressive typography, Marsel FX gives editors more ways to bring their ideas to life.

### ✨ What's Inside?

- 🎨 **14 visual modules** in Marsel Prism
- ⚡ **6 motion effect modules** in Marsel Motion
- 🎬 **Motion Studio** for native image and text animations
- 🎞️ **72 FilmCraft presets**
- 🛠️ Customizable controls and editable animations
- 💜 Free and open-source code
- 🚀 Continuous development and improvements

## ✦ Explore the Packs

Two creative collections. Different possibilities. One ecosystem.

### 💎 MARSEL PRISM

**Light. Color. Texture. Atmosphere.**

Marsel Prism focuses on visual storytelling, cinematic looks, creative image processing, and lighting effects.

Create atmospheric edits, experiment with texture, or give your footage an entirely different character.

**Highlights include:**

| ✦ Effect | Description |
|---|---|
| Film Looks | 12 film-inspired color palettes |
| Deep Glow | Rich, customizable lighting and glow |
| Bloom | Soft cinematic highlight glow |
| RGB Split | Creative color channel separation |
| JPEG Damage | Digital compression-inspired artifacts |
| Pixelate | Pixel-based visual stylization |
| Selective Light | Artistic lighting adjustments |
| Gradient Shadow | Customizable shadow treatments |
| Film Grain | Analog-inspired visual texture |

*The full Prism collection contains 14 visual modules.*

### ⚡ MARSEL MOTION

**Movement. Energy. Personality.**

Marsel Motion is designed to bring life into otherwise static edits.

From energetic camera movement and glitches to smooth image entrances and animated typography, Motion provides tools to make every frame feel more expressive.

**Motion highlights:**

- Camera movement and shake effects
- Digital glitches and animated fragmentation
- Flash effects and dynamic visual motion
- Native image animation presets
- Native text animation presets
- In / Out / Loop animation modes
- Custom easing and animation curves

### ✦ Motion Studio

**Your motion. Your timing. Your style.**

Motion Studio introduces native image and text animation controls directly into the editing workflow.

- **IN** — Design how elements enter the scene
- **OUT** — Control how elements leave
- **LOOP** — Add repeating motion
- **EASING** — Customize animation timing
- **CURVES** — Fine-tune movement
- **EDITABLE KEYS** — Keep native timeline control

No need to sacrifice creative flexibility for convenience.

## ✦ Installation

**Getting started with Marsel FX.**

### Windows Installer

The project includes a Windows installer system designed to simplify installation and removal.

When a packaged release becomes available:

1. Open the [**Releases**](https://github.com/maarrsel/Marsel-Fx-/releases) page.
2. Download `Marsel-Fx-3.0-Setup.exe`.
3. Run the installer.
4. Select your preferred packs and supported applications.
5. Complete the installation.

The installer supports both installing and removing the packs.

**The installer executable is distributed separately from the source code and may not be available until a release is published.**

### Compatibility

| Application | Included Content |
|---|---|
| **EffectCraft** | 20 WASM effect modules and Marsel Motion Studio |
| **FilmCraft** | 72 native effect presets |
| **Platform** | Windows installer |

> **Note:** FilmCraft presets use FilmCraft's native effects rather than EffectCraft's WASM modules. Their controls, functionality, and appearance may differ. The animated previews primarily demonstrate EffectCraft output.
